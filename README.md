# カイジポーカー

カイジ風ダークテーマの5枚ブラフポーカー（日本語）。
オフライン（対CPU）とオンライン対人戦の両方に対応しています。

---

## 遊び方

### オフライン（対CPU）

1. `index.html` をブラウザで開く（または `dist.html` を直接開く）
2. プレイヤー人数を選択して「ゲーム開始」
3. 手札から **2枚** をクリックして選択し「開示確定」
4. 各ターンで「カードを引く」か「カードを交換提案」を選択
5. 全員が2ターン終えたら役を比べて勝敗決定

> **`dist.html`** は CSS/JS をすべて1ファイルに結合済み。GitHubからダウンロードして単体で動作します。

---

### オンライン対戦

#### 事前準備（初回のみ）

Supabase ダッシュボード（[supabase.com](https://supabase.com)）の **SQL Editor** で以下を実行してください：

```sql
CREATE TABLE rooms (
  code       CHAR(4)      PRIMARY KEY,
  state      JSONB        NOT NULL DEFAULT '{}',
  created_at TIMESTAMPTZ  DEFAULT NOW()
);

ALTER PUBLICATION supabase_realtime ADD TABLE rooms;
```

#### 対戦手順

**ホスト（部屋を作る側）**
1. `index.html` をブラウザで開く
2. 「オンライン対戦」をクリック
3. プレイヤー名を入力して「ルーム作成」
4. 表示された **4文字のコード** を対戦相手に伝える
5. 全員が入室したら「ゲーム開始」をクリック

**参加者（部屋に入る側）**
1. `index.html` をブラウザで開く
2. 「オンライン対戦」をクリック
3. プレイヤー名を入力し、ホストから受け取ったコードを入力して「参加する」
4. ホストが開始するまで待機

## ゲームルール

| フェーズ | 内容 |
|---|---|
| **開示フェーズ** | 手札5枚から2枚を選んで全員に公開する（合計値が小さい順にターン順が決まる） |
| **ターン（×2周）** | カードを1枚引く（山札と交換）か、他プレイヤーにカード交換を提案する |
| **ショーダウン** | 5枚の役を比べて最強手の人が勝利 |

### 役の強さ（弱→強）

ハイカード → ワンペア → ツーペア → スリーカード → ストレート → フラッシュ → フルハウス → フォーカード → ストレートフラッシュ → ロイヤルフラッシュ

## ファイル構成

```
kaiji_poker/
├── index.html   # HTML構造（オンライン画面含む）
├── style.css    # カイジ風ダークテーマ
├── game.js      # ゲームロジック + Supabase連携
├── dist.html    # ビルド済み単一ファイル（配布用）
└── build.py     # dist.html を生成するスクリプト
```

### dist.html の再生成

```bash
python3 build.py
```
